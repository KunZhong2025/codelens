# 码见 CodeLens

> 通过屏幕与摄像头，在物理隔离的设备之间传递文本和文件。

码见把内容变成屏幕上的二维码，让另一台设备的摄像头把它读回来。**不联网、不登录、不经过任何服务器**——传递介质只有光。

## 三步

1. **生成** —— 在发送端输入文本或拖入文件，短内容生成一张标准二维码，长内容自动切分成动态二维码流。
2. **扫描** —— 在接收端打开码见并对准屏幕，识别成功后摄像头自动关闭。
3. **核对** —— 接收端显示完整内容与 SHA-256 校验值，确认一致后再复制或保存。

## 免责声明

码见是个人开发的独立工具，**发布版本未做代码签名**。Windows 首次运行时可能出现 SmartScreen 提示，选择「仍要运行」即可。

码见**不做端到端加密**。屏幕上的二维码内容对任何能拍到屏幕的人或设备都是明文。需要保护内容时，请先用你自己的工具加密，并使用中性文件名再传输。

本工具仅适用于你有权处理的数据。请自行确认使用方式符合所在环境的规定。
